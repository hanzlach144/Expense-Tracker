# Expense Tracker

A modern Expense Tracker built with HTML, CSS and JavaScript.

## Features

- Budget Management
- Add / Edit / Delete Expenses
- Search & Filters
- Category & Month Filtering
- Expense Analytics Dashboard
- Pie Chart & Bar Chart (Chart.js)
- PDF Export (jsPDF)
- Dark Mode
- Local Storage
- Responsive Design

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- jsPDF
